# customer-shopping-behaviour
Analyzed 3,900 retail transactions using Python, SQL, and Power BI to uncover customer buying patterns, discount behavior, shipping preferences, and subscription impact. Built automated ETL pipelines, segmented shoppers into New, Returning, and Loyal tiers, and delivered an interactive dashboard



🛍️ Customer Shopping Behavior Analysis
An end-to-end data analytics project examining 3,900 retail transactions using Python, SQL, and Power BI to uncover customer buying patterns, segmentation, and revenue drivers.

🛠️ Tech Stack
Python (Pandas, SQLAlchemy): Data cleaning, feature engineering, and SQL database ingestion.
SQL (PostgreSQL / MySQL): Business metric queries, customer segmentation, and product ranking.
Power BI: Interactive dashboard (customer_behaviour dashboard.pbix).
PowerPoint: Executive summary deck (Customer-Shopping-Behavior-Analysis.pptx).

📂 Files
customer_shopping_behavior.csv.xlsx – Raw dataset (3,900 rows, 18 columns).
sales data cleaning python.ipynb – Data cleaning, feature engineering, and database upload.
mysql customer_behaviour.sql – 10 SQL queries answering key business questions.
customer_behaviour dashboard.pbix – Interactive Power BI report.
Customer-Shopping-Behavior-Analysis.pptx – Findings and recommendations presentation.

💡 Key Insights
Customer Tiers: 50% New, 35% Returning, and 15% Loyal shoppers.
Shipping Impact: Express shipping users spend 12% more per order ($65 vs. $58).
Subscriptions: Subscribers have a 78% repeat purchase rate and drive 45% of total revenue.
Revenue & Discounts: Female shoppers generate slightly higher revenue, while high-value discount users still spend above the overall average.

🚀 Recommendations
Grow Subscriptions: Target repeat buyers (>5 purchases) with exclusive subscriber perks.
Retention Funnel: Incentivize first-time buyers (50% of users) to make repeat purchases.
Targeted Promotions: Promote express shipping and highlight top-rated products in campaigns.
